Sprint 3 Report
Mutalist

Shane Ganz, Josiah Norton, Nathaniel Teh

## What's New (User Facing)
* Official Branding: Rebranded the application to Mutalist with a custom logo and a cohesive dark-themed GUI.
* Cross-Platform Support: Full compilation and support for Windows, Linux, and Mac.
* Enhanced Block Logic: Introduced the Leetspeak block and specialized UI for pend block previews.
* Robust File Management: Integrated system save menus, collision prevention, and included premade wordlists.
* User Experience: Added keyboard shortcuts, a top menu bar, undo/redo functionality, and a progress bar.

## Work Summary (Developer Facing)
This final sprint was focused on transitioning the prototype into a deployable application. This included making sure performance stable across all platforms. We also implemented a state management system to support undo/redo functionality, keyboard shortcuts, and the ability to save and load canvas states. Additionally, we fully completed the leetspeak block and added previews to the pend blocks. To ensure that our application was fully functional, we created an automated testing suite to verify accuracy and collision prevention. Finally, we enhanced the UI by adding a dark theme and selection outlines. 

## Further Work
While the core requirements have been fulfilled, future versions may include more complex mutation blocks.
